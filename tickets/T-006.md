## Context
Two parts. (1) `scripts/pull_captions.sh <channel_url> <outdir>`: yt-dlp wrapper — `--skip-download --write-auto-subs --write-subs --sub-langs en.*` + `--write-info-json`, `--download-archive` for resumability, `--sleep-requests 1.5` politeness. (2) `onrecord/ingest/youtube.py`: parse a directory of `.vtt` + `.info.json` pairs → `Doc` rows (JSONL). Window caption cues into ~75-second segments; `id="yt:<video_id>:seg<nnn>"`, `deep_link="https://youtube.com/watch?v=<id>&t=<start_s>s"`, `source_type="county_meeting"`, `venue_type="sworn"`, date + jurisdiction from info.json/registry entry passed as arg. Dedupe repeated auto-caption rollup lines (consecutive duplicate text). Tests run on committed fixture VTT/info.json files — NEVER the network.

## Acceptance Criteria
- **AC-1**: Given fixture VTT with cues spanning 0-200s, when parsed with 75s windows, then 3 Docs produced with correct `&t=` starts (0,75,150) and concatenated cue text.
- **AC-2**: Given auto-caption VTT with consecutive duplicated rollup lines, when parsed, then text contains no adjacent duplicate lines.
- **AC-3**: Given a video with no English subs available (no .vtt), when the directory is parsed, then the video is skipped with a logged warning line — no exception, other videos still parse.
- **AC-4**: Given fixture info.json with upload_date `20250611`, when Docs are built, then `date=="2025-06-11"` and jurisdiction/venue fields populate from the provided registry entry.
- **AC-5**: Given malformed/truncated VTT, when parsed, then the file is skipped with a warning — no crash.

## Test Plan
