## Scope
Pull + parse SEC Form 4 (insider transaction) filings for the 76 registry
tickers. CIK resolution via SEC company_tickers.json; per-CIK submissions
API filtered to form=4 since 2024-01-01; each ownershipDocument XML parsed
to rows {ticker, cik, filer_name, filer_title, is_officer, is_director,
transaction_date, code (P/S/A/...), shares, price_per_share, value,
shares_owned_after, filing_url, accession}. Output:
artifacts/form4/insider_transactions.jsonl + a checksummed manifest.
Keyless (SEC UA-header etiquette, <=8 req/s, resumable). ACs: parser
fixtures (buy, sell, multi-transaction, amended 4/A skipped), CIK mapping
including dotted tickers, malformed-XML skip-and-log, dedupe by
(accession, transaction row).
