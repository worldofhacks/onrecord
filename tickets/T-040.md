## Scope
Extraction pass (claude, batched) over promise-dense candidate docs
(keyword-prefiltered: committed/will create/jobs/revenue/limit/by 20xx,
capped ~2000 docs, est $4-8) -> evalsets-style artifact
evalsets/promises.jsonl {promise_id, doc_id, deep_link, date, jurisdiction,
ticker, quote (verbatim), category (jobs|tax|water|power|timeline|other),
quantified (bool), value_text}. Every promise carries its receipt
verbatim - extraction may SELECT quotes, never paraphrase them into the
quote field (anti-fabrication pin: quote must be a substring of doc text,
enforced in code + tests). API: GET /api/promises?jurisdiction=&ticker=&
category=&k= -> rows + counts. UI: Ledger tab goes live - filterable
promise cards with SWORN/FILED badges and deep links; "soon" chip removed.
