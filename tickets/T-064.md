## The flow (frozen UX contract)

receipts -> evidence tray (user picks up to 6) -> recipient (jurisdiction board
from data/jurisdiction_boards.json: 51 curated office addresses + Legistar
officerecords roster where available) -> sender (user name + return address,
Lob-verified, $0.05) -> DRAFT (claude-opus-5 under the grounded-answer
discipline: verbatim quotes only, deep links printed, refusal if evidence is
thin) -> REVIEW (the exact rendered PDF, editable) -> CONFIRM (cost shown,
explicit typed confirmation, consent logged: timestamp + letter sha256) ->
SEND (Lob POST /v1/letters, use_type operational, NO send_date so the 4h
cancel window stays) -> UNDO banner (DELETE /v1/letters/{id} inside 4h) ->
webhook status -> the letter becomes a receipt in the user's action history.

## Honesty + safety pins (frozen)

- A letter NEVER sends without the explicit confirm step; no batch/auto path exists in code.
- Sender is always the USER (name + verified return address); footer: "Prepared and mailed via OnRecord at the request of [name], a resident of [jurisdiction]" (Lob AUP no-false-origin clause).
- Draft quotes are verbatim-pinned (substring of source docs) — the Promise Ledger discipline applied to output.
- Env-gated: ONRECORD_LOB_KEY absent -> the whole feature 503s flat (the platform's keyless ladder); test-mode key -> Lob test environment end to end.
- Rate/cost caps: per-user daily letter cap + global daily cap (rate-limiter conventions from T-034).
