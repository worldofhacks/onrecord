## Scope
Deterministic (no-LLM) evasion-marker scoring over county-meeting docs:
frozen marker lexicon ("cannot comment", "get back to you", "not at
liberty", "no comment", "defer to", "take that offline", ...), scored per
jurisdiction as markers per 1000 docs with a minimum-doc floor (>=200 docs
to qualify). API: GET /api/dodge -> ranked jurisdictions {jurisdiction,
docs, markers, per_1000, sample_receipts[3]}. UI: card on the Ledger view.
Every number click-throughs to sample receipts. Marker lexicon committed +
frozen-tested; methodology note in the UI (transparent, reproducible).
