## Context
The honesty machinery. `pooling.py`: given a query + corpus JSONL + k, gather candidates from independent sources — (a) substring/keyword grep over doc text, (b) `rank_bm25` (the reference oracle lib) top-k, (c) random-sample spice (2-3 docs) — dedupe, **shuffle with a seeded RNG, strip any which-source markers**. `judgments.py` CLI (`python -m onrecord.eval.judgments`): interactive loop — FIRST prompts for the relevance criterion text (stored with the query, written before candidates are shown), then shows each candidate's text (no scores, no source), takes grade 0/1/2 or s(kip), appends rows `{query_id, query, criterion, doc_id, grade}` to `evalsets/judgments.jsonl`; resumable (skips already-judged (query_id, doc_id) pairs).

## Acceptance Criteria
- **AC-1**: Given a corpus and query, when pooled with k=10 per source, then the candidate list is deduped, shuffled (seeded), and contains no source attribution in what the judge sees.
- **AC-2**: Given scripted stdin grades, when the CLI judges 3 candidates, then judgments.jsonl gains exactly 3 well-formed rows including the criterion text.
- **AC-3**: Given an existing judgments.jsonl with (q1, docA) judged, when the CLI reruns for q1, then docA is not re-presented (resumable).
- **AC-4**: Given the criterion prompt, when the session starts, then the criterion is captured BEFORE any candidate text is displayed (order asserted via scripted IO).
