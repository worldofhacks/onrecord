## Context
The assignment's core oracle: our BM25 vs `rank_bm25.BM25Okapi` on the IDENTICAL analyzed token stream (this isolates ranking math from tokenization). rank_bm25 is already a dep (pooling). `onrecord/eval/differential.py`: `run_differential(index_docs, queries, k1, b, k=10) -> report` that builds both our index and BM25Okapi from the same token lists, compares per-query rankings and scores. Note rank_bm25's BM25Okapi uses a different IDF flooring (epsilon clamp) — the pinned comparison: score agreement within rtol=1e-6 after matching parameters where formulas coincide (its idf uses ln((N-df+0.5)/(df+0.5)+1)? verify against the library source and PIN what "match" means in the test docstring — top-k ORDER agreement (Kendall tau or exact prefix match) is the primary assertion, score-tolerance secondary where formulas align).

## Acceptance Criteria
- **AC-1**: Given a 50-doc synthetic corpus + 10 queries, our top-10 ranking ORDER matches BM25Okapi's exactly (identical tokens, matched k1/b) for every query.
- **AC-2**: Given matched formulas, per-doc scores agree within documented tolerance; any systematic deviation is a failure.
- **AC-3**: Property: a doc gaining one occurrence of a query term never drops below an otherwise-identical doc lacking it (assignment invariant 3).
- **AC-4**: `python -m onrecord.eval.differential` runs the suite against a committed fixture corpus and exits 0 on agreement / 1 with a per-query diff table on divergence.
