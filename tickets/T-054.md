## Context

Owner wants semantic headroom. The deployed store is `text-embedding-3-small`
@ 1536 (fp16 matrix 0.89 GB, NDCG@10 0.538 on the four-arm pool — current
best mode). Candidate: `text-embedding-3-large` @ 3072 (full dims, no
Matryoshka truncation), ~$9.50 re-embed over ~73.5M corpus tokens.

## Protocol (pooling-bias-aware — metrics.md Finding 2 applies)

1. **Build** `artifacts/embeddings-3large` with the existing
   `EmbeddingStore.embed_corpus` (checkpointed, resumable; identity
   chunking via `chunk_corpus`, same as deployed). No new production code —
   operational driver in scratchpad only.
2. **First read (biased)**: `python -m onrecord.rag.modes --store
   artifacts/embeddings-3large --history
   evalsets/modes-scoreboard-3large.jsonl` against the EXISTING judgment
   pool. Documented as a lower bound: 3-large's unique finds are unjudged
   and score 0 — the same mechanism that slandered semantic pre-repair.
3. **Fifth pooling arm**: pool 3-large-semantic's novel (query, doc) pairs
   over the 100 queries; label with gpt-5.6-sol under the session-3/4
   criterion-first protocol; provenance sidecar
   (`judgment-session-5-provenance.json`); append to
   `evalsets/judgments.jsonl`.
4. **Honest comparison**: re-score BOTH stores (all three modes each)
   against the augmented pool; both readings reported side by side. The
   augmented pool may move the baseline's numbers too — report old-pool and
   augmented-pool readings for both models; never compare across pools.

## Acceptance criteria

- AC-1: new store identity is (`text-embedding-3-large`, 3072) and covers
  all 289,536 chunk_ids; store-identity guard exercised (mismatched
  provider raises).
- AC-2: comparison table shows both models × both pools; the deploy
  decision cites only same-pool deltas.
- AC-3: labeling session has a provenance sidecar and zero unparsed rows;
  judgments.jsonl grows append-only.
- AC-4: no production code changes without tests-first; a deploy swap (if
  the numbers justify it) is a separate owner-approved ticket folded into
  the corpus-v3 lane (T-053 pin: post-demo-video).
