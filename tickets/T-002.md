## Context
Implements frozen `analyze(text) -> list[str]` from T-001. Token position == list index (the index derives positions from it). Design: Unicode NFKC → lowercase → split on non-alphanumeric (keep digits; `q3`, `10-k` → `10`,`k`), drop empty tokens. NO stemming, NO stopword removal (documented v1 choice, Spec §3).

## Acceptance Criteria
- **AC-1**: Given `"The Applicant's 240MW request—Loudoun County."`, when analyzed, then tokens are `["the","applicant","s","240mw","request","loudoun","county"]`.
- **AC-2**: Given text with unicode (`"Curaçao ＭＳＦＴ"`), when analyzed, then NFKC+casefold applies → `["curacao","msft"]` is NOT required for ç (no transliteration) but `ＭＳＦＴ`→`msft` is; `"curaçao"` keeps `ç`.
- **AC-3**: Given empty string or whitespace/punctuation-only input, when analyzed, then `[]` — no exception.
- **AC-4**: Given any already-analyzed output re-joined with spaces, when re-analyzed, then tokens are unchanged (idempotence — property test).

## Test Plan
- Unit (deterministic): AC-1..3 exact cases + CJK/emoji don't crash.
- Property (hypothesis): AC-4 idempotence; output tokens always match `[a-z0-9]+` or non-Latin word chars; never raises on arbitrary unicode.

## Definition of Done
- [ ] ACs tested + green; local gates green
- [ ] Docstring documents the v1 no-stemming/no-stopwords decision

## Out of Scope
Stemming, stopwords, query parsing, snippets.
