## Acceptance Criteria
- **AC-1**: Given a tmp corpus JSONL of ≥20 docs across all 3 source types, when `build_corpus` + CLI `search "substation" --op AND` run, then results print with deep links and exit 0.

- **AC-4**: Given a fresh `git clone` of the repo into a tmp dir (local file clone), when `make setup && make demo` runs with no network flags set, then it completes successfully end-to-end (the MVP-7 gate, asserted in a test marked `slow`).
