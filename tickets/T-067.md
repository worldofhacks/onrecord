## Context

`_citations()` sets `snippet = chunk.text[:160]` — a blind head-truncation
(onrecord/rag/answer.py:295, 309). The receipt is correct (right chunk, working
deep link) but the previewed text is the chunk's opening, which may not be the
passage supporting the claim. `onrecord/search/ranked.py:_snippet()` already
does query-centered windowing for search results; citations should get the
same treatment, centered on the question's content terms.

DEFERRED DELIBERATELY: `retrieved[].snippet == chunk.text[:160]` is a FROZEN
pin (tests/unit/rag/test_answer.py docstring item 2), so this needs a
banner-documented amendment plus evidence — not a change to make hours before
a graded submission. Logged instead as a known limitation in docs/metrics.md.

## Acceptance criteria (sketch)
- AC-1: snippet contains the earliest question-term occurrence when one exists, with an ellipsis marker when the window does not start at 0.
- AC-2: no question-term overlap falls back to today's head-truncation (backward compatible).
- AC-3: bounded length unchanged; frozen test amended with banner + evidence, never silently rewritten.
