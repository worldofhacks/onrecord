## Context
Civic channels trim, re-upload, and delete meeting VODs over time. Captions
were captured at pull time and remain authentic, but a dead deep link makes a
receipt unreplayable — and today the UI would render it silently broken.
Measured baseline 2026-08-13: 0% rot (30/30 random sample alive), so this is
preventive, not urgent.

## Sketch
- Batch sweep: one YouTube oembed HEAD/GET per unique video id (~11K), rate-
  gentle, resumable; writes artifacts/linkhealth.jsonl {video_id, status,
  checked_at}.
- Doc annotation: /api/search + /api/answer citation payloads gain
  link_status (alive|removed|unchecked) via a startup-loaded map.
- UI: removed links render "source removed — caption preserved as captured
  ⟨pull date⟩" instead of a dead href; SWORN/FILED badge unchanged.
- Re-run cadence: manual or weekly; a run is cheap (~11K requests).

## Also noted here (known-cosmetic, no ticket of its own)
Pre-hydration console noise from SVG template bindings ({{ mv.x }} etc. in
sc-for templates): browsers validate SVG attributes before the engine stamps
real values. Invisible to users; fixing it means restructuring the template
runtime (e.g. <template>-wrapping) — not worth the regression risk alone.
