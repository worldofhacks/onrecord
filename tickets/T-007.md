## Context
`onrecord/ingest/edgar.py` with two layers. (1) Fetch layer: ticker → CIK (bundled `company_tickers.json` fixture approach — download once in live mode), submissions JSON → recent 10-K/10-Q/8-K accession list → primary doc HTML. Politeness: `User-Agent` header with contact email env var (`EDGAR_UA`), ≤8 req/s, retry w/ backoff. (2) Parse layer (pure, tested): filing HTML → text → split into section Docs — 10-K/Q: split on Item headings (regex `Item\s+\d+[A-Z]?\.?`), keep Item 1A Risk Factors + Item 7 MD&A (+ 8-K: full doc, exhibits EX-99 included when present). `id="edgar:<ticker>:<accession>:<section>"`, `deep_link` = EDGAR archives URL, `source_type="filing"`, `venue_type="coached"`. Live fetch behind `fetch_filings(ticker, forms, limit)`; tests exercise parse layer + fetch layer with mocked httpx transport — NEVER live network.

## Acceptance Criteria
- **AC-1**: Given fixture 10-K HTML with Items 1, 1A, 7, 8, when parsed, then Docs for 1A and 7 exist with heading-bounded text and correct ids/deep links.
- **AC-2**: Given fixture 8-K with an EX-99.1 press-release exhibit, when parsed, then body and exhibit each become a Doc.
- **AC-3**: Given a submissions JSON fixture, when recent filings are listed with `forms={"10-K","8-K"}, limit=5`, then only those forms, newest first, ≤5.
- **AC-4**: Given HTML with nested tables/scripts/entities, when text-extracted, then output contains no tags/scripts and entities are decoded.
- **AC-5**: Given a 404/timeout (mocked transport), when fetching, then retry w/ backoff then skip-and-log — no exception escapes; other tickers proceed.
