## Measured (prod, Railway shared vCPU, 2026-08-14)
- lexical k=20: 1.0s | semantic k=20: 3.0s | hybrid k=20: 7.8s
- two concurrent hybrids: 10.7s and 16.9s (mutual degradation)
- The UI's former 8s budget guaranteed hybrid failure -> apiDown -> "engine
  unreachable" (mitigated in the same PR: 30s heavy-mode budget, superseded-
  request aborts, auto-reprobe, honest empty-state).

## Root cause
T-022's frozen design pins full-depth fusion: `hybrid_search` runs
`ranked_search(k=index.doc_count())` (289K-deep BM25 sort) plus
`_semantic_ranking(k=len(chunks))` (fp16 matmul over 289K x 1536 — numpy
fp16 is emulated on x86, no BLAS). Measured fast on the dev M-series
machine; 6-8x slower on prod vCPU.

## Options (adjudicate before build)
1. Bounded fusion depth (fuse top-N per arm, N~2000): near-identical top-20
   RRF results, biggest win, but amends the frozen "RRF needs deep
   rankings" pin — needs a differential test (full-depth vs bounded top-k
   overlap on the 100-query judgment set) as the amendment evidence.
2. fp32 matrix cast at load: matmul drops to BLAS speed (~0.3s) but +0.9GB
   RAM on a container measured 5.8G steady/7.4G peak against an 8G cap —
   needs a memory head-room measurement first.
3. Both (bounded depth makes the fp32 cast unnecessary for search; answer
   pipeline hybrid retrieval also gains ~7s/answer).

## RESOLUTION (2026-08-14)
Option 1 implemented: `hybrid_search(..., fusion_depth=None)` — additive
param, `None` preserves the frozen full-depth behavior bit for bit (pinned
by test); the API passes `ONRECORD_FUSION_DEPTH` (default 2000, `0`
restores full depth). The frozen signature pin and the FULL-DEPTH module
docstring were amended with banners. Option 2 (fp32 cast) was REJECTED on
inspection: the scoring loop already casts block-wise to fp32 for BLAS —
the real full-depth costs were the 289K-row per-result hash-verification
loop, the full lexical materialization, and the full-sort tail, all of
which the bound eliminates.

Differential evidence (real corpus-v2, all 100 judgment queries,
committed as `evalsets/t037-differential.json`): top-20 overlap 99.5%
mean / 90% min, 98/100 exactly identical top-10, NDCG@10 0.4309 full vs
0.4315 bounded, latency 2.609s -> 0.631s (4.1x) on dev hardware.
