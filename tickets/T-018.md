## Context
Snapshots are versioned (corpus/v1 exists; corpus-v2 lands today) but nothing records WHICH version an index/scoreboard row came from — `_corpus_version()` in onrecord/eval/run.py returns the `"unversioned"` placeholder. This ticket makes version a first-class artifact. All changes are ADDITIVE: every existing frozen test (tests/unit/test_metrics.py, tests/integration/test_e2e.py, tests/unit/ingest/**) stays untouched and green; existing defaults (`corpus/v1`, `artifacts/index`) are byte-compatible when `--version` is omitted.

- **build_corpus** (`onrecord/ingest/build_corpus.py`): new `--version N` CLI arg (int, default `1`). When given, the default `--out` becomes `corpus/v{N}` (explicit `--out` still wins). After a successful build, write `manifest.json` into BOTH the snapshot out dir and the `--index-out` dir (the version travels with the built index — eval and the API read the index, not the snapshot). Exact key set (6 keys): `{"corpus_version": "v{N}", "created_at": <ISO-8601 UTC>, "doc_count": <rows indexed>, "source_counts": {<source_type>: n, ...}, "git_sha": <HEAD or "unknown">, "snapshot_sha256": <sha256 hexdigest of the written corpus.jsonl.gz>}`. The checksum key serves the snapshot-distribution recommendation attached to open question #7 (plan-review I-4: v2 may ship as a Release asset; the committed manifest + checksum is what proves a fetched/rebuilt snapshot is the frozen one). Expose `MANIFEST_FILENAME = "manifest.json"` and `read_manifest(dir_path) -> dict | None` (tolerant: missing/corrupt → `None`, never raises) as module-level public API — T-022/T-025/T-026 runners and later tooling consume `read_manifest` (locked-decision: constants-contract convention per the SCOREBOARD_PATH lesson, commit 048b849).
- **Makefile**: `ingest` target honors `V` and `RAW` — `V ?= 1`, target runs `uv run python -m onrecord.ingest.build_corpus --version $(V)` plus `--raw-dir $(RAW)` when `RAW` is set (default raw dir unchanged). `make ingest V=2` is the spec-pinned command shape (locked-decision, spec §7); the pulled v2 captions live OUTSIDE the repo (HANDOFF), so the operational rebuild is `make ingest V=2 RAW=<parsed-raw-dir>` (plan-review M-11 — without RAW passthrough the pinned command cannot perform the rebuild it exists for).
- **eval/run.py**: `_corpus_version()` reads `read_manifest(Path(os.environ.get("ONRECORD_INDEX", DEFAULT_INDEX_PATH)))` and returns its `corpus_version`; any failure → `"unversioned"` (backward-compatible; the history-row KEY SET is frozen by test_metrics.py and does not change — only the value does).

Orchestrator note (not this ticket): the corpus-v2 re-parse/rebuild itself is an operational action (HANDOFF Thursday item 1) — this ticket only ships the machinery it runs through. Judged doc ids survive v2 verbatim; nothing here may transform doc ids (locked-decision).

## Acceptance Criteria
- **AC-1**: Given a tmp raw dir and `--version 2` with no explicit `--out`, build_corpus writes `<cwd>/corpus/v2/corpus.jsonl.gz` (arg-parser default derivation tested via the parser/main seam with tmp cwd) and `manifest.json` with EXACTLY the 6 keys above in both the out dir and the index-out dir; `doc_count` equals the number of successfully-indexed rows, `source_counts` sums to it, and `snapshot_sha256` equals the sha256 of the written gz file (recomputed in the test).
- **AC-2**: With `--version` omitted, defaults are unchanged (`corpus/v1`, `artifacts/index` equivalents in tmp) and the manifest says `"corpus_version": "v1"` — existing callers see no behavior change beyond the new manifest file.
- **AC-3**: `read_manifest` returns the parsed dict for a valid manifest; returns `None` (no exception) for a missing dir, missing file, or corrupt JSON.
- **AC-4**: With `ONRECORD_INDEX` pointing at a tmp index dir containing a v2 manifest, `run()` (retrieve_fn-injected, tmp judgments/history) appends a history row whose `corpus_version == "v2"`; with no manifest present the row says `"unversioned"` (regression guard).
- **AC-5**: The Makefile `ingest` recipe contains the `--version $(V)` wiring with `V ?= 1` and the conditional `--raw-dir $(RAW)` passthrough (asserted textually — `make` itself isn't invoked in unit tests; the orchestrator's Tier-2 gate runs `make ingest V=2 RAW=...` live at the v2 rebuild).
