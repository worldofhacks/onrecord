## Context
Single-service deployment: FastAPI serves the API AND the static UI. Changes to onrecord/api.py:
1. **Static UI**: mount `ui/` — GET / returns the contents of `ui/index.html` (the design app; the orchestrator places it — tests may write a stub ui/index.html + ui/support.js in tmp and point an env var `ONRECORD_UI_DIR` at it, default `ui/`). `./support.js` must be served with a JS content type. Unknown non-/api paths → serve index (SPA-ish fallback) EXCEPT paths with extensions (404).
2. **GET /api/prices/{ticker}?range=365&threshold=5.0**: wires onrecord.ingest.prices.api_payload (corpus path from `ONRECORD_CORPUS` env, default corpus/v1/corpus.jsonl.gz — note api_payload takes a corpus JSONL path; gz support: read via gzip when suffix .gz — extend the call site, not prices.py). Unknown/unsafe ticker → 200 with empty series (the prices module already returns [] + logs). Response = api_payload's exact shape.
3. **Index bootstrap**: lifespan currently 503s when ONRECORD_INDEX missing. New behavior: if index dir missing but the corpus snapshot exists (env `ONRECORD_CORPUS`), build the index at startup (build_corpus's build+save path or InvertedIndex.build over the snapshot rows) then serve. Railway cold-start depends on this.
4. **PORT env**: document `uvicorn onrecord.api:app --host 0.0.0.0 --port $PORT` in README Deploy section; Dockerfile (python:3.12-slim + uv, copy repo, uv sync --no-dev, CMD honoring $PORT) + railway.json ({"build":{"builder":"DOCKERFILE"},"deploy":{"startCommand":...}}).

## Acceptance Criteria
- **AC-1**: GET / returns 200 text/html with the stub index content; GET /support.js returns 200 with a JavaScript content type; GET /api/search still works (no route shadowing).
- **AC-2**: GET /api/prices/VST with a tmp corpus + fixture-cached price file returns the api_payload shape (series + significant_moves[].nearby_receipts); hostile ticker → 200 {"ticker":..., "series":[], "significant_moves":[]}.
- **AC-3**: With ONRECORD_INDEX pointing at a missing dir and ONRECORD_CORPUS at a valid tmp snapshot (.jsonl.gz), app startup builds the index and /api/search returns results (no 503).
- **AC-4**: With both index missing and corpus missing, data endpoints 503 with the existing clear message; / (UI) still serves.
